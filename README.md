# 🏫 College Club Management Portal

A single-page, self-contained college club management portal for managing clubs, events, announcements, and members — built entirely with vanilla HTML, CSS, and JavaScript.

---

## ✨ Features

- **Admin Dashboard** — Manage announcements, events, and club members
- **Student Dashboard** — View announcements, events, and member lists
- **5 Pre-configured Clubs** — Sports, Gaming, Coding, Music, and Art clubs
- **Event Management** — Create, edit, and delete events with date/time/location
- **Announcement System** — Post and clear club-specific announcements with auto-rotating slider
- **Member Management** — Add/remove members with demo seed data
- **Persistent Storage** — All data saved to localStorage
- **Club-Scoped Isolation** — Each club has its own independent data
- **Responsive Design** — Clean card-based UI with CSS custom properties

---

## 🛠️ Tech Stack

| Component | Technology |
|-----------|------------|
| Frontend | HTML, CSS, JavaScript |
| Storage | localStorage |
| Design | Responsive CSS, Custom Properties |
